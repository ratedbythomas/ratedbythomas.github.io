# ratedbythomas.github.io
Rated by Thomas Website

Content conventions: Locations are alphabetical; bar rankings are Thomas’s subjective city order. Drinks within a bar appear in his preference order and do not get individual scores. Use a venue photo for ranking covers when available and Thomas’s drink photos on review pages. Optional World’s 50 Best metadata belongs in `.review-sub` as muted `.world-50-meta` text after the visit date, using Thomas-supplied historical and/or current ranking only. Do not infer rankings.

World’s 50 Best optional metadata example (only after Thomas supplies the figures): `<span class="world-50-meta">#25 in The World’s 50 Best Bars when visited · Currently #72</span>`. Omit either phrase independently when only one figure is known.
